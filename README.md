# American Accent Trainings — Official Website

A single-page website for **American Accent Trainings** in Lahore, Pakistan, tailored for freelancers and remote professionals working with USA and Canadian clients.

## Features
- **Accurate Template Redesign**: Faithfully re-creates the entire official design mockup in pure HTML5, CSS3, and JavaScript.
- **Responsive Layout**: Designed for mobile phones, tablets, and desktop displays.
- **Hero Composition**: Interactive hero section with headline, 3-point benefits, "Start Your Training Today" button, and "Watch Video" course overview modal.
- **Interactive Audio Sampler**: Hear standard American English pronunciation using the built-in browser speech synthesis engine.
- **WhatsApp Integration**: Instant enquiry form with pre-filled messages and fixed pulsing WhatsApp chat button.
- **Location & Contact**: Address in Kot Lakhpat, Lahore, with embedded Google Maps and click-to-call.

## How to Deploy on Vercel for Free (via GitHub)

### Step 1: Push this code to GitHub
1. Open your terminal in this project folder:
   ```bash
   git add .
   git commit -m "American Accent Trainings website"
   ```
2. Create a new repository on [GitHub](https://github.com/new) (e.g. `american-accent-trainings`).
3. Link and push your repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/american-accent-trainings.git
   git branch -M main
   git push -u origin main
   ```

### Step 2: Deploy to Vercel
1. Log in to [Vercel](https://vercel.com) (free account).
2. Click **"Add New..."** -> **"Project"**.
3. Select your GitHub repository (`american-accent-trainings`) and click **"Import"**.
4. Vercel will automatically detect the settings from `vercel.json`:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"**.

Your website will be live on your free Vercel `.vercel.app` URL within seconds!
